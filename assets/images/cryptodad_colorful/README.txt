These are the colorful Crypto Dad game images from earlier sessions.

They were used in the version of the game that was tested with 200,000+ Monte Carlo simulations.

The game logic in GrokBuild_cryptoDad_v1.html is the same one that was validated in those simulations (player-driven: safe choices stabilize, risky/illegal choices increase Heat and destroy family/money).

Use the images from this folder in the game for state-based visuals (family levels, heat events, endings).

Green CRT versions are also available in the sibling folder for fallback.
