// HUB UI EXAMPLES v2

New set - not the old chip-row / rail / dock. Built against the current live hub (title + war path + map chips + NEW banner + 2-col accordion + long footer). Goal: easier scan, clearer primary actions, less stack noise, still CRT / degen.

PROBLEM WITH CURRENT HUB
Too many layers fighting: status * war path * map chips * NEW banner * accordion * war briefing modal * footer wall. Same destinations appear twice. Accordions hide the map. Phone becomes a long scroll of tiny headers.

PICK ONE reply like: “Hub D” or “Hub F but keep accordion for DEGEN$”
D * Command tiles E * Clean BBS list F * Zone cards G * Phone stack H * Hybrid (rec) <- live hub old gallery
D - COMMAND TILES primary actions first
Big strike tiles for SWAP / ARCADE / GAMES / BASEMENT, then a quiet secondary list.
Why: cold users hit the money paths in 1 tap. No hunting accordion.
E - CLEAN BBS LIST numbered * one column
Single-column numbered directory. No chips, no dual grid. Fat rows. Keyboard 1 - 9 friendly.
Why: maximum clarity, pure terminal. Least “UI kit,” most DOS.
F - ZONE CARDS STRIKE * PLAY * BUILD * INTEL
Four zones with short blurbs + 2 - 3 links each. Grouped by intent, not random accordion.
Why: teaches the bunker map without a separate // MAP strip.
G - PHONE STACK mobile-first
One hero CTA (SWAP), then full-width section cards. No 2-col desktop grid fighting thumbs.
Why: phones are the real battlefield. Desktop still looks fine stacked.
H - HYBRID ★ recommended tiles + clean list * less noise
Best of both: 3 primary command tiles, one status line (no war essay), compact secondary menu, short OPSEC footer. Keeps degen energy, kills the clutter pile-up.
Why: UI-friendly without becoming Uniswap. This is the one I’d ship if you want friendlier + still warlike.
