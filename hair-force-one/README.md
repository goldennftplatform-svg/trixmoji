# HAIR FORCE ONE

Doswapz Arcade rhythm prototype. Looks use the full concept art screenshots — **no sprites**.

## Play

Open `index.html` in Chrome or Edge.

| Key | Action |
|-----|--------|
| ← ↓ ↑ → | Hit notes |
| A S W D | Same |
| Space | Start / retry |

Live neon note highway sits over the right side of the gameplay art. Hits punch the background; misses shake it.

## Mechanics (prototype)

- 4-lane timing: Perfect / Great / Good / Miss
- Score + combo
- Short chart + metronome beeps (no licensed song yet)
