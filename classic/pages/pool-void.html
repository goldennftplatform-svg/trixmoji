THE DESK THE WELLS POINTS VOIDS POOLVOID.APP GUIDE HUB

POOL VOID IS JIMMY'S WORK. DOSWAPZ DOES NOT RUN IT. poolvoid.app calls itself an archive of everything that enters. The public guide calls it a wishing well: a person sends ETH, a token, or an artwork to poolvoid.eth or void.eth, and the send is the wish. This page only reads that desk. It does not connect a wallet, and it does not move a coin.

// 01 · THE DESK POOLVOID.APP

The site is a dark archive. The meta line is "POOL VOID. An archive of everything that enters." The home screen shows the latest arrival, three counters, and a recent-arrivals table. A lookup box takes an address, an ENS name, or a profile link. Jimmy's post on 21 Oct 2026 says you do not need to connect. You enter the address and the receipt is there.

Connect is optional. The wallet list on 22 Oct 2026 is an injected wallet, a Base Account, and Coinbase Wallet. The same screen says mobile wallets will be available when WalletConnect is configured. Signing in is for a profile and for sending from the site. Looking up a receipt does not require that signature.

A profile card shows transactions, transfers, ETH, artworks, a score, and unlocks. The receipt is drawn on the page. You can download it. The app logs a failed download as "[POOL VOID] Receipt download failed". That receipt is the page's picture of what the index already stored. It is separate from the older POOL VOID RECEIPT NFT.

poolvoid.app/api/resolve confirms the names: void.eth and poolvoid.eth resolve to those two addresses. A transfer row names the target, the chain, the asset, the amount, and the time. The home table is that feed.

void.eth on Ethereum is a contract. Its bytecode is the Gnosis Safe proxy: the masterCopy selector is in the code. poolvoid.net's update says that in December 2024 a majority of the assets were secured to a gnosis multisig at void.eth. This desk confirmed the proxy. It did not recount the assets.

The public guide still tells a person to send to poolvoid.eth. The app counts both names. Sending is a normal chain transfer. poolvoid.net says to commit only what you can lose, and it says no refunds. This DOSWAPZ page has no send button.

// 03 · POINTS THE RULE LIST

GET /api/scoring/rules returned 177 rules. The source field on the achievement rows is https://www.poolvoid.net/guide. The app's own line for how a score is built: multipliers start at 1, add together, then multiply base points. Colored voids dissolve points. Resurrection resets earlier voids. Edits apply to all indexed history.

Each rule in that response is marked once, not repeating. The older guide still says a multiplier can be sent an unlimited number of times, and that a negative multiplier flips the sign on even and odd counts. Where the guide and the live rule list disagree, the receipt you see on poolvoid.app is using the live list.
