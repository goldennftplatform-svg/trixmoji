WALLET ROUTE TEST

This experimental test checks whether MetaMask sends a fully prepared transaction directly or wraps it through the smart account. It is for the wallet ending aa3E on Ethereum mainnet.

It does not deposit or transfer #6 or any other known Ethscription. It sends 0 ETH and random, unused 32-byte test data to 0x000000000000000000000000000000000000dEaD. You must approve it in your wallet and pay the network gas fee. A direct result is evidence for this test transaction only; it does not prove a future escrow deposit.

Review MetaMask carefully. If it asks to upgrade or change the account, cancel. No wallet setting change is required by this test.

Connect the test wallet to begin.
