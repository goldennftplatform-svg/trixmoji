LAUNCH PREP (NOT LIVE YET)
==========================
Updated: 2026-07-16

WHAT THIS IS
------------
Scaffold to track Pokémon / sports / TCG product status across:
  Walmart, Target, Best Buy, Dick's, Pokémon Center, Amazon (stubs).

Current site behavior UNCHANGED:
  - Attic UI still loads /assets/data/attic-drops.json by default
  - No retailer is polled
  - Browser alerts remain a client demo until launch wiring

WHAT WAS PREPARED
-----------------
Data:
  assets/data/attic-watchlist.json     multi-retailer watchlist (live:false)
  assets/data/attic-drops.json         existing manual board (still used)

API (dormant for tracking):
  GET  /api/attic-drops                public board JSON (safe)
  GET  /api/attic-drops?meta=1         flags + recent events
  POST /api/attic-drops                admin actions (secret required)
  POST /api/attic-drops-check          dry-run unless ATTIC_DROPS_LIVE=1

Lib:
  api/lib/attic-drops-store.js
  api/lib/attic-retailers/index.js     all adapters stubbed

Frontend:
  assets/js/attic/drops.js
    - default: static JSON
    - optional: ?dropsApi=1 or window.DOSWAPZ_ATTIC_DROPS_USE_API = true

Netlify:
  netlify/functions/attic-drops.js
  netlify/functions/attic-drops-check.js

Vercel routes:
  /api/attic-drops

ADMIN EXAMPLES (when secret is set — still dry-run if LIVE off)
---------------------------------------------------------------
# Public board
curl -s https://YOUR-SITE/api/attic-drops?meta=1

# Dry-run check (LIVE must be off → armed:false)
curl -s -X POST https://YOUR-SITE/api/attic-drops-check \
  -H "x-attic-admin: YOUR_SECRET"

# Reload bundled watchlist into KV
curl -s -X POST https://YOUR-SITE/api/attic-drops \
  -H "x-attic-admin: YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"reload-watchlist-bundled\"}"


SAFETY
------
- POST set-watchlist forces live:false on stored watchlist
- Checkers no-op network when ATTIC_DROPS_LIVE !== 1
- Stubs never claim stock
- Watchlist rows with sku REPLACE_ME are always skipped
