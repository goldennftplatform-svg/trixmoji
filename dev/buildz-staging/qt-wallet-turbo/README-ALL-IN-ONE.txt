QUANTUM TRADER — ALL-IN-ONE DOS DASHBOARD

This version has NO browser dashboard.
The dashboard is built directly into live-scout.js and renders in the same terminal.

START:
1. Put your existing .env file in this folder.
2. Double-click START-TRADER.cmd.
3. The terminal itself becomes the dashboard.

It displays:
- Wallet SOL balance
- Approx wallet USD value
- Open positions
- Buys / sells
- Day P/L
- Consecutive losses
- Top token signals
- Scores
- 5m / 1h changes
- Liquidity
- Trade activity and errors
- Bot status / uptime

The bot's original strategy and safety guards are preserved.

IMPORTANT:
- Your .env/private key is intentionally NOT included.
- START-TRADER.cmd enables live trading.
- START-PAPER.cmd runs the paper/scout mode.
- Ctrl+C stops the bot.
- No Chrome, localhost site, or separate dashboard process is required.
