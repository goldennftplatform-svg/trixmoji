# Crypto School
A beginner-first crypto education prototype.

## Run
Open `index.html` locally, or drag the folder into Netlify Drop.

## Included
- 8 learning levels
- 40+ bite-sized lessons
- Simple explanations and analogies
- Quick-check quizzes
- Local progress saved in the browser
- Bitcoin, blockchain, wallets, Ethereum, Solana, DeFi and security
- No transactions, trading, or wallet connections
