QUANTUS ONE-BUTTON DASHBOARD

1. Extract this ZIP.
2. Double-click ONE-BUTTON-START.bat.
3. Do not run any other file.

The launcher:
- checks WSL
- starts the dashboard server
- opens the dashboard in your browser
- starts the existing Quantus miner

Dashboard: http://localhost:8787

The dashboard reads the live miner log from:
~/Quantus-OneClick/miner.log

IMPORTANT:
"Imported blocks" are blocks received by your node from the network.
"Solutions found" only counts explicit mining solution/found/accepted messages.
They are intentionally separate.

To stop mining: press Ctrl+C in the miner window.
